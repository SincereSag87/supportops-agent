# Screenshot Guide

No screenshots are committed in v1.0.0. This avoids accidentally capturing private desktop paths, credentials, or local environment details.

Recommended manual screenshots for a portfolio page:

1. Operations tab showing synthetic customer/order state.
2. Agent Request tab showing medium refund awaiting approval.
3. Approvals tab after approval execution.
4. Audit Trail tab showing policy, approval, and action events.
5. Evaluation tab showing the scripted benchmark result.
6. System tab showing health and metrics.

Only synthetic Northstar Commerce data should be visible.
